# 📚 Biblioteca de Deconstrucción de Referentes

> **Propósito:** Carpeta de ingeniería inversa de referentes del mercado. Aquí se desmontan creadores/cuentas referentes en patrones visuales, narrativos y de conversión para alimentar los frameworks de `Estrategia/`.

Esta carpeta se entrega **vacía intencionalmente** en la plantilla. Cada usuario debe poblar su propia biblioteca con los referentes de su nicho.

## Cómo poblarla

1. Duplica [[Templates/referente_perfil|la plantilla de perfil de referente]] una vez por referente.
2. Nómbrala como carpeta por referente: `Referentes-y-Benchmarking/<slug-referente>/perfil.md`.
3. Enlaza cada perfil desde el [[Estrategia/README|índice de Estrategia]].

## Reglas

- Un referente = una carpeta = un `perfil.md` (más análisis auxiliares si aplica).
- Los patrones descubiertos se convierten en reglas en `SOPs/` o frameworks en `Estrategia/Frameworks-de-Guionizacion/`, no quedan solo como notas.
- Nunca copiar copy: se decodifican *mecanismos*, no textos.
